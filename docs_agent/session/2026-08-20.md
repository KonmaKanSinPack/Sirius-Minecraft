### 架构决策（为什么）

- **原语同步阻塞 + 协作式取消**（非 Numen 式异步受理）：AgentLoop 本就串行执行工具，同步原语让 60s 行走只占 1 个 tool call 位、期间零 VLM 调用；急停通过微步内查取消标志保证 ≤1s。M5 分层时再升级异步受理（task/task_finished 协议帧与 TaskCard 模型已在 protocol/ 备好，不用动）
- **bridge 保持哑管道，只加两个向后兼容参数**（filter / hold_ms）：符合"输入标准化、感知原语化"既定分工；brain 侧组合一切
- **模组兼容零硬编码**（Numen 手段，`core/tools/ToolParse.java:37-56`、`core/init/InitTag.java:74-91`）：filter 走 registry name + `#tag` 前缀展开；不枚举 vanilla 名单
- **count 语义 = 目标方块挖除数**（Numen 是物品增量需背包基线，我们暂无背包快照工具，记可选增强）

**T2 原语（`sirius_brain/agent/primitives.py`）**

```python
class Primitives:
    """任务级复合动作原语。Numen 式契约：意图进、结果出、失败带下一步建议。
    同步阻塞 + 协作式取消：微步循环（poll_interval≈0.5s）每步查 cancel()。"""

    def __init__(self, client, *, poll_interval=0.5): ...

    async def walk_to(self, x: float, z: float, y: float | None = None,
                      timeout: float = 120.0, cancel=None) -> ToolOutcome:
        # 1) command(f"#goto {x} {y or 当前y} {z}")   # 前缀#客户端拦截，不达服务器
        # 2) 轮询 getStats：水平距离 ≤2 → 成功（附最终坐标）
        # 3) 看门狗：15s 距离无进展 → 重发一次 #goto（只重发一次，Numen 近重试档）
        # 4) cancel() → 发 #stop → 返回"已中止（当前坐标）"
        # 5) 超时 → #stop + "路程仍在推进但超预算；同参数重发可续走，或改用更近途经点"（Numen 健康超时话术，MoveToCompanionTask.java:410-424）

    async def dig_block(self, x: int, y: int, z: int, timeout: float = 30.0, cancel=None):
        # 0) world.query(filter=[该坐标现方块]) 复核存在；已空 → 直接成功
        # 1) getStats 距离 >4.5 → "目标 x,y,z 距离 n 格超出触及范围；先 walkTo 到它旁边再挖"（Numen GoToThenDoTask.java:76-81 话术）
        # 2) 循环：lookAt(x+0.5, y+0.5, z+0.5) → input.click(button=0, hold_ms=600) → sleep(0.5)
        #    → world.query 复核消失 → 成功"已挖掉 minecraft:spruce_log (x,y,z)"
        # 3) 连续 8 段仍在 → "无法破坏该方块（可能被遮挡/工具不足/保护规则）；screenshot 观察或换目标"

    async def collect_block(self, block_ids: list[str], count: int, cancel=None):
        # 循环 min(count,…) 次：
        #   world.query(type=blocks, filter=block_ids) → 空 → break
        #   取最近 → walk_to(邻近，方块坐标±1.5) → dig_block → destroyed += 1
        # 收尾（Numen MineCompanionTask.java:886-897 契约）：
        #   destroyed ≥ count → "已挖到 n/count 个 <ids>"
        #   0 < destroyed < count → "已挖到 n/count；范围内已无更多，可接受或走远再试"（仍算成功）
        #   destroyed == 0 → 失败："范围 64 格内未找到 <ids>；确认 ID（含 #tag 写法）或走近些"
```
